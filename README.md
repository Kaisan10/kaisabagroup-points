# かい鯖グループポイント

「かい鯖グループポイント」は、様々なサービスやアプリケーション間で共通して利用できる経済システムです。
APIを通じて外部サービスと連携し、ポイントの獲得や消費、ユーザー間の移動などを管理します。

## 主な機能

- **ポイント管理**: ユーザーごとのポイント残高の管理
- **API連携**: 外部サービスからの取引
- **OAuth / Webhook連携**: フォーラム活動等によるポイント獲得
- **セキュアな取引**: トランザクションと排他制御（行ロック）によるポイントの整合性保証
- **管理者ダッシュボード**: サーバー登録、APIキー管理、利用履歴の確認など

## テクノロジースタック

- **バックエンド**: Node.js, Express
- **データベース**: PostgreSQL
- **テンプレートエンジン**: EJS
- **テスト**: Jest

## ローカル環境のセットアップ

### 注意
- Discourseの環境が必要です。


1. **リポジトリのクローン**
   ```bash
   git clone https://github.com/kaisan10/kaisabagroup-points.git
   cd kaisabagroup-points
   ```

2. **依存関係のインストール**
   ```bash
   npm install
   ```

3. **環境変数の設定**
   `.env.example` をコピーして `.env` ファイルを作成し、必要な設定を記述します。
   ```bash
   cp .env.example .env
   ```

4. **データベースの準備**
   PostgreSQLを起動し、`.env` で設定したデータベース（例: `kaisaba_points`）を作成します。
   テーブルのマイグレーションはアプリケーション起動時に自動的に実行されます。

5. **アプリケーションの起動**
   ```bash
   npm start
   ```

6. **テストの実行**
   ```bash
   npm run test
   ```
