# 本番環境へのデプロイ手順

本プロジェクトでは、開発環境(`kaisabagroup-points-dev`)の `dev` ブランチで作業を行い、
完了後に本番環境(`kaisabagroup-points`)の `main` ブランチに反映する運用を行っています。

## デプロイフロー

1. **開発環境でのマージ**
   GitHub 上で `dev` ブランチから `main` ブランチへ Pull Request を作成し、マージします。

2. **本番環境への適用**
   サーバーに接続し、本番環境のディレクトリで `git pull` を実行します。

   ```bash
   cd /home/kaisabagroup-points
   git checkout main
   git pull origin main
   ```

3. **アプリの再起動**
   変更を反映させるためにアプリの再起動を行います。

## 注意事項
- 本番環境での直接のコード変更は避けてください。
- ポイントの増減・ユーザーの作成など、ポイントの有無が変わる操作は絶対に行わないでください。
- 取り返しのつかない操作の前には必ずバックアップを取るようにしてください。
